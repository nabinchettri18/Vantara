# Day 1 — Data Foundation

## Objective
Set up the repository, environment, obtain the UCI Online Retail II dataset, and establish initial validation checks.

## Dataset
UCI Online Retail II, dataset ID 502.

## Initial checks
- Required columns
- Data types
- Missing Customer ID values
- Duplicate records
- Date range
- Negative quantities (returns/cancellations)
- Zero/negative prices
- Unique customers and invoices

## Important rule
Do not silently remove returns or unusual transactions during Day 1. They are part of the data-quality analysis and may carry predictive signal.
